# Bundled reference data

`places.json.gz` is adapted from the **GeoNames geographical database**,
https://www.geonames.org/, under the Creative Commons Attribution 4.0 license:
https://creativecommons.org/licenses/by/4.0/.

Source: https://download.geonames.org/export/dump/ (`cities15000.zip`,
`countryInfo.txt`, `admin1CodesASCII.txt`). Changes: selected columns converted to
compressed JSON, country and region labels joined, aliases deduplicated. GeoNames
does not endorse this application. See `manifest.json` for source/output hashes.

`timezones.zip` contains public-domain IANA timezone data, version 2025b, compiled
TZif files imported from `/usr/share/zoneinfo` on the development system.
Source and background: https://data.iana.org/time-zones/tz-link.html.

Generated by `scripts/import_places.py`; do not edit generated data manually.
